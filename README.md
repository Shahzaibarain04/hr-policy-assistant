# HR Policy Assistant (RAG)

An AI-powered HR Policy Assistant built using Streamlit, FAISS, SentenceTransformers, PyMuPDF, and Groq (`openai/gpt-oss-20b`).

## How to Use
1. Enter your **Groq API Key** in the sidebar.
2. Upload any HR Policy document in `.pdf` format.
3. Ask questions regarding company policy to get instant, context-aware answers.
